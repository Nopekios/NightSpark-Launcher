# NightSpark

NightSpark 是一个 Windows 平台的 Minecraft: Java Edition 启动器。

本仓库是 NightSpark 的源码，下载请前往 [Releases](https://github.com/Nopekios/NightSpark-Launcher/releases)。

---

NightSpark is a Minecraft: Java Edition launcher for Windows. This repository contains its source code. Downloads are on [Releases](https://github.com/Nopekios/NightSpark-Launcher/releases).

---

## 构建 / Build

自行构建请运行 `scripts/build.ps1`（Windows，需 Node.js 与 Rust 工具链）。这样构建出的包水印标记为 `OFFICIAL=false`，不携带官方签名，不作为官方发布版本。

To build from source, run `scripts/build.ps1` on Windows (Node.js + Rust toolchain required). Such builds carry a watermark with `OFFICIAL=false`, are not signed by the author, and are not official releases.
